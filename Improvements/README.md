# Improvements

Эта папка хранит новые продуктовые и технические доработки проекта.

Цель:
- фиксировать постановку задачи;
- раскладывать несколько вариантов решения;
- сохранять историю обсуждения;
- отдельно фиксировать финальный выбор, не затирая предыдущие варианты.

## Правило работы

Для каждой новой доработки создается отдельная папка в формате:

`YYYY-MM-DD-short-name`

Пример:

`2026-04-01-channel-subscriptions`

## Рекомендуемая структура внутри задачи

- `00-problem-and-goals.md` — что хотим получить, зачем и какие ограничения.
- `01-solution-options.md` — несколько вариантов решения с плюсами, минусами и требованиями.
- `FINAL-DECISION-TEMPLATE.md` — шаблон для итогового выбранного решения.
- `final-decision-YYYY-MM-DD.md` — появляется после обсуждения, когда решение выбрано.

## Важный принцип

Файлы с альтернативами не удаляются после принятия решения.

Они нужны для:
- отслеживания логики выбора;
- возврата к старым идеям;
- понимания, почему были отвергнуты другие варианты;
- упрощения дальнейших продуктовых обсуждений.
