# User Experience

## Для обычного пользователя

Обычный пользователь видит привычный мессенджер:

- список чатов;
- переписку;
- обычное общение.

Если у него нет нужного тарифного права аккаунта, он не видит возможности:

- создать свой платный канал;
- создать свой паблик как владелец монетизируемого пространства.

## Для пользователя с платным тарифом аккаунта

Если у пользователя есть подходящий account plan:

- у него появляется возможность создавать группы;
- у него появляется возможность создавать паблики/каналы;
- у него появляется интерфейс управления участниками.

## Для подписчика канала

Подписчик видит:

- страницу канала;
- открыт ли доступ сейчас;
- если доступа нет, сообщение, что доступ закрыт;
- при необходимости ссылку или кнопку для внешней оплаты.

После внешней оплаты:

- пользователь попадает в разрешенный список;
- получает доступ к каналу.

Если доступ снят:

- канал снова закрывается;
- пользователя можно исключить.

## Для владельца канала

Владелец канала видит:

- настройки канала;
- тип канала: публичный или приватный;
- список участников;
- список разрешенных участников;
- возможность добавить пользователя в доступ;
- возможность убрать пользователя из доступа;
- возможность исключить участника из канала.

## Как это ощущается пользователю

Для подписчика логика простая:

- оплатил вне приложения;
- получил доступ внутри приложения.

Для владельца логика тоже простая:

- получает деньги во внешнем сервисе;
- управляет доступом в приложении.

## Что важно не ломать в UX

- не показывать пользователю внутреннюю финансовую кухню;
- не смешивать оплату и чат-интерфейс;
- не показывать лишние биллинговые сущности;
- держать фокус на доступе, а не на бухгалтерии.
