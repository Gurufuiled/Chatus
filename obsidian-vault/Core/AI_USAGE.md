# Использование этого vault с ИИ (экономия токенов)

## Принцип

1. **Не вставляй весь vault в чат.** Модель получает контекст по **открытым файлам** и **@mentions** в Cursor.
2. **Сначала ядро:** один запрос — прочитать [[CURRENT_FOCUS]] + при необходимости [[PROJECT_BRIEF]].
3. **Одна тема = одна заметка** в `Topics/`; если файл разросся — разбей и дай ссылки из [[../Home|Home]].

## В Cursor

- Напиши в чате: *«см. `obsidian-vault/Core/CURRENT_FOCUS.md`»* или прикрепи файл через **@**.
- Для большой фичи: добавь **@** на `Topics/Channels.md` (или другую тему), а не весь `mobile/`.

## В Obsidian

- Обновляй [[CURRENT_FOCUS]] раз в день или при смене задачи — этого часто достаточно для «где мы сейчас».
- [[DECISIONS]] — только итог (1–3 предложения на пункт), без переписки.

## Чего избегать

- Один файл на тысячи строк.
- Дублирование того же текста, что уже в `.cursor/rules/project.mdc` — лучше **ссылка**: «см. правило project» или краткий выжимкой в [[PROJECT_BRIEF]].
