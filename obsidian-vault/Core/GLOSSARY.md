# Глоссарий

| Термин | Значение |
|--------|----------|
| P2P / DataChannel | WebRTC для прямой передачи данных между клиентами |
| Fallback | При недоступности P2P — доставка через сервер (WS) |
| Channel / канал | Публичная лента постов; может быть связанный чат обсуждения |
| Discussion | Тред комментариев к посту канала (отдельный chat в БД) |
| uniffi | FFI между Rust и Kotlin/Swift |
| Zustand | Стейт-менеджер на клиенте |
