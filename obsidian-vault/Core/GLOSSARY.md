# Глоссарий

| Термин | Значение |
|--------|----------|
| Signaling (WebRTC) | Отдельный WebSocket для SDP/ICE при **звонках** (не для текста сообщений) |
| Offline queue | Очередь отправки в SQLite при отсутствии сети |
| Channel / канал | Публичная лента постов; может быть связанный чат обсуждения |
| Discussion | Тред комментариев к посту канала (отдельный chat в БД) |
| Channel slug | Публичный идентификатор канала в ссылке (латиница, цифры, `_`, min 5 симв.) |
| Invite link | Доп. ссылка с лимитом по времени/числу пользователей |
| uniffi | FFI между Rust и Kotlin/Swift |
| Zustand | Стейт-менеджер на клиенте |

Дополняй по мере появления жаргона в команде.
