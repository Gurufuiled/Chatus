# Vault Obsidian для проекта Chatus / P2P Messenger

## Как открыть в Obsidian

1. Запусти **Obsidian**.
2. **Open folder as vault** → выбери эту папку:  
   `.../testik/obsidian-vault`
3. В каталоге уже есть **`.obsidian/`**: включены поиск, граф ссылок, backlinks, шаблоны, новые файлы по умолчанию в `Inbox/`.
4. Шаблон «фокус дня»: `Templates/Daily-focus.md` — вставка через команду **Insert template** (палитра команд: Ctrl/Cmd+P → «template»).

Если vault уже был открыт до обновления Git: **закрой vault и открой папку снова**, чтобы подтянулись настройки.

Эта папка лежит **внутри репозитория**, чтобы Git синхронизировал заметки между машинами и чтобы Cursor мог ссылаться на файлы по пути.

## Зачем это нужно

- **Меньше токенов:** нейросети не нужно «помнить» всё из чата — достаточно прочитать 1–3 короткие заметки из `Core/`.
- **Один источник правды:** решения и фокус работы — в Markdown, а не только в переписке.
