## 2026-06-29 - [FlatList Inline Props Anti-Pattern]
**Learning:** React Native's `FlatList` performs sub-optimally when passed inline functions or element definitions for props like `renderItem`, `keyExtractor`, `ListHeaderComponent`, and `ListEmptyComponent` because new references are generated on every render, invalidating memoization.
**Action:** Extract and memoize these props using `React.useCallback` and `React.useMemo`.
