## 2024-05-18 - Avoid widespread formatting changes in commits
**Learning:** Running an auto-formatter (like prettier) without being careful about its scope or the repository's configuration can lead to massive formatting diffs (e.g., single to double quotes) that pollute the git history and obscure the actual changes being reviewed.
**Action:** Always restrict formatting to only the explicitly modified files or lines, or ensure the formatter closely matches the existing styles in the file. Avoid generic `npx prettier --write .` or using it on whole files without checking diffs first.
