## 2024-06-25 - React Native FlatList Separator Re-renders
**Learning:** Passing an inline anonymous function or unmemoized component definition directly to `ItemSeparatorComponent` in `FlatList` or `SectionList` is a major performance anti-pattern. React Native treats this as a brand new component type on every render cycle. This forces every single separator in the list to completely unmount and remount from the DOM instead of just updating, destroying scroll performance and memory on large lists.
**Action:** Always extract `ItemSeparatorComponent` functions to the top level of the component and wrap them in `React.useCallback`. E.g., `const renderSeparator = useCallback(() => <View style={styles.sep} />, [styles.sep]);`
