## 2026-06-20 - Memoizing list separator components
**Learning:** In React Native lists (`FlatList`, `SectionList`), passing inline functions for structural props like `ItemSeparatorComponent` (e.g., `() => <View />`) is an anti-pattern. This forces React to treat the element as a new component type on every render, causing all separators to unmount and remount, which can degrade scroll performance and cause UI glitches.
**Action:** Always extract and memoize separator and other structural components using `React.useCallback` or move them outside the component if they don't depend on props/state, so the list can reuse them effectively without re-rendering.
