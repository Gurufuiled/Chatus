## 2026-06-23 - Optimize ItemSeparatorComponent in Lists
**Learning:** Passing an inline functional component (like `() => <View />`) to `ItemSeparatorComponent` in React Native `FlatList` or `SectionList` is an anti-pattern. React Native treats it as a brand-new component type on every render of the parent, which forces React to unmount and remount every separator component in the list rather than updating them, leading to performance issues.
**Action:** Always extract and memoize these functions using `React.useCallback` to keep component references stable, allowing React to properly diff and retain the separator components.
