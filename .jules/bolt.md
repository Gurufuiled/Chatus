## 2026-06-19 - Inline ItemSeparatorComponent in Lists
**Learning:** Passing inline components (e.g., `() => <View />`) to `ItemSeparatorComponent` in React Native `FlatList` and `SectionList` is an anti-pattern. React treats it as a new component type on every render, causing unmounts and remounts of separators.
**Action:** Always extract `ItemSeparatorComponent` logic into memoized components or use `React.useCallback` to preserve component instance references across renders.
