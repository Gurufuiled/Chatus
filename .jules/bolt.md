## 2026-06-18 - FlatList inline function performance anti-patterns
**Learning:** Using inline functions for props like `ItemSeparatorComponent` (e.g. `ItemSeparatorComponent={() => <View />}`) in React Native's `FlatList` causes the component to be unmounted and remounted on every list re-render, leading to performance degradation, especially during rapid state changes like search filtering. Furthermore, wrapping list item components in `React.memo` is rendered ineffective if the parent list passes inline callbacks to them.
**Action:** Always memoize `ItemSeparatorComponent` using `React.useCallback`. When rendering list items, pass stable function references directly to memoized child components to ensure their `React.memo` checks succeed.
