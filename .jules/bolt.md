## 2024-05-18 - [FlatList performance in React Native]
**Learning:** React Native's `FlatList` component expects stable references for props like `data`, `renderItem`, `keyExtractor`, `ListHeaderComponent`, and `ListEmptyComponent` to leverage its internal `PureComponent` optimizations. Passing inline arrays, objects, or anonymous functions directly to these props in the render phase forces constant re-evaluations and unnecessary unmounting/remounting or re-rendering of list items, severely degrading scrolling performance.
**Action:** Always extract these properties and wrap them in `useMemo` or `useCallback` when using `FlatList`. Make sure the dependencies are accurate to avoid stale closures. Ensure dependencies arrays correctly identify and track changes required for re-evaluation.
