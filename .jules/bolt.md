**Learning:** When using `<FlatList>` components for long feeds in React Native (e.g. chat dialogs or contacts), rendering performance can degrade without explicit virtualization props, particularly on Android. However, enabling `removeClippedSubviews` indiscriminately on iOS when a search input is active can cause severe rendering glitches and layout thrashing.
