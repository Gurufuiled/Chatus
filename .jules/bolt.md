## 2026-06-12 - Memoizing FlatList component props
**Learning:** In React Native, passing inline functions (like `() => <View />`) directly to structural props like `ItemSeparatorComponent` in `FlatList` or `SectionList` causes React to perceive a new component type on every render. This completely unmounts and remounts all separators instead of just updating them, causing major scroll jank and GC pressure on large lists.
**Action:** Always extract components passed to list props and memoize them via `React.useCallback` or define them outside the component body.
