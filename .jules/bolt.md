## 2026-06-28 - [FlatList Inline Components Anti-Pattern]
**Learning:** Passing inline arrow functions or literal JSX elements to structural FlatList props (like `renderItem`, `ListHeaderComponent`, `ListEmptyComponent`, etc.) forces React to treat them as new component types on every parent render. This defeats FlatList optimizations and causes unnecessary unmounting/remounting of items.
**Action:** Always extract and memoize these props using `React.useCallback` or `React.useMemo` to pass stable references and preserve list performance.
