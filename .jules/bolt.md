## 2024-05-23 - Avoid inline ItemSeparatorComponent
**Learning:** Passing an inline anonymous function `() => <View />` to `FlatList`'s `ItemSeparatorComponent` causes React to treat the separator as a new component type on every render. This forces unmounting and remounting of all separators, causing unnecessary memory allocation and CPU overhead during scroll.
**Action:** Always extract `ItemSeparatorComponent` definitions to a stable reference using `React.useCallback` or move them outside the component if they don't depend on props.
