## 2026-06-14 - List Item Render Callbacks
**Learning:** Passing inline anonymous callbacks (like `onPress={(chatId) => handlePress(chatId)}`) to `React.memo` components in `FlatList`'s `renderItem` causes the equality check to fail on every render of the parent list.
**Action:** Always create stable handler references using `useCallback` in the parent list component and adjust the child row component's props so they accept the full context (e.g. the entire `item` object) avoiding inline closures altogether.
