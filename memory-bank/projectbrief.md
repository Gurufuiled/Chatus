# Project brief — P2P Messenger (Telegram-like)

## Цель
Мобильный мессенджер максимально близкий к Telegram по функционалу и UX.

## Ключевые особенности
- Доставка текста, голоса и медиа в первую очередь через **P2P (WebRTC DataChannel)**.
- При невозможности P2P — **fallback на WebSocket** (сервер relay).
- **Offline-first**: локальное хранение в **SQLite** (в Rust, не в RN).

## Архитектура (высокоуровнево)
- **Rust Core** — бизнес-логика, БД, сеть, P2P, синхронизация; FFI через **uniffi**.
- **React Native (Expo)** — UI, запись медиа, анимации; общение с Rust через сгенерированный мост.

## Границы
- Бэкенд (HTTP API, WS, signaling) — внешний контракт, не «наш» код целиком, но клиент с ним интегрирован.
